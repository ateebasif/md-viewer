# Getting started

Back to the [showcase](../showcase.md).

## Install

Run the installer from the project folder:

```bash
./install.sh
```

## Open something

```bash
mdv README.md      # a single file
mdv ~/notes        # a folder, with a sidebar
mdv                # the current folder
```

> [!TIP]
> Leave the tab open and edit the file in any editor. The page updates as you save.
